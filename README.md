📺 ShowStream

Aplicación Android para consultar un catálogo de series de televisión.

📌 Descripción del proyecto

ShowStream es una aplicación móvil desarrollada como parte del Endterm del módulo M07 - Desarrollo de interfaces.

Su objetivo es ofrecer una aplicación para consultar un catálogo de series, visualizar información detallada y gestionar la autenticación de usuarios.
